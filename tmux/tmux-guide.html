tmux keybind guide

Prefix: C-Space — hold a or ; (Ctrl via homerow mods) + tap Space

Concepts

Pane
A split within a single screen. Like nvim splits. Multiple panes visible at once side by side or stacked.
Window
A full-screen tab containing one or more panes. Like browser tabs. Only one window visible at a time. Names shown in the status bar.
Session
A complete workspace containing multiple windows. Survives disconnection — detach with C-Space d, reconnect with tmux attach. Name shown in Ghostty tab.
Typical workflow: One session per project. Multiple windows per concern (editor, server, tests). Panes for side-by-side within a window.

Session Persistence

Two plugins work together to keep your sessions alive across restarts:

tmux-resurrect — manual snapshots

Saves and restores the full session state: windows, panes, layouts, and working directories. Running processes (e.g. rails s, nvim) are restored to their pane positions.

KeyAction
prefix C-s Save current session state to disk
prefix C-r Restore last saved state

tmux-continuum — automatic saves

Wraps resurrect with a background timer. No manual saves needed for day-to-day use.

BehaviourDetail
Auto-save interval Every 15 minutes
Auto-restore On tmux start (after reboot or cold start)
Storage location ~/.local/share/tmux/resurrect/
What survives a reboot: session names, window names, pane layouts, working directories, pane contents (scrollback). Running processes are re-launched if they were started from the shell.
What does not survive: live process state (e.g. in-memory Rails server data), SSH connections, anything not started from a shell command.

Nvim & Tmux Integration

Several config options work together to make nvim feel native inside tmux:

Seamless pane / split navigation

vim-tmux-navigator makes C-h/j/k/l work across both nvim splits and tmux panes with no prefix. The tmux config detects when a pane is running nvim using is_vim (checks the process name via ps) and forwards the keystrokes to nvim instead of switching panes. The nvim plugin does the mirror image.

KeyWhere it goes
no prefix C-h/j/k/l Nvim split if nvim is focused, tmux pane otherwise

Escape latency

escape-time 0 removes tmux's default 500ms wait after Esc. Without this, every Esc in nvim (exit insert mode, dismiss popups) has a noticeable delay because tmux waits to see if it's the start of an escape sequence.

Focus events

focus-events on forwards terminal focus events into tmux panes. Nvim uses these to trigger autoread, so buffers automatically reload when you switch back to a pane where a file changed on disk (e.g. after a git pull or formatter run in another pane).

True color

The terminal-overrides lines add RGB capability for both xterm-256color and xterm-ghostty. Without these, nvim colorschemes fall back to 256-color approximations and gruvbox-material looks wrong.

Undercurl (LSP diagnostics)

The Smulx and Setulc overrides enable undercurl rendering and colored underlines inside tmux. Nvim uses these for LSP error/warning/hint indicators. Without them, diagnostics show as plain underlines with no color.

Clipboard

set-clipboard on + pbcopy as the copy command means nvim's "+y yank and tmux copy mode both write to the macOS system clipboard. No separate clipboard plugin needed in nvim for this to work inside tmux.

Notifications (Ghostty passthrough)

allow-passthrough on lets applications inside tmux send OSC escape sequences directly to Ghostty. Claude Code uses OSC sequences to trigger native notifications — without passthrough, tmux drops them before they reach Ghostty.

Ghostty Integration

FeatureHow it works
Tab name = session name set-titles on + set-titles-string "#S" sends the session name as the terminal title via OSC 0. Ghostty uses that for the tab label.
Native notifications allow-passthrough on lets OSC notification sequences from inner apps (Claude Code, etc.) reach Ghostty unmodified.
Bell notifications bell-action any + visual-bell off ensures terminal bell passes through to Ghostty for bell-based notification triggers.
True color xterm-ghostty:RGB override enables 24-bit color when Ghostty sets TERM=xterm-ghostty.
