tmux keybind guide

Prefix: C-a — hold a (Ctrl via homerow mods) + tap a

Concepts

Session: "work"                     Session: "personal"
├── Window 1: "editor"              ├── Window 1: "dotfiles"
│   ├── Pane (nvim)                 │   └── Pane (nvim)
│   └── Pane (terminal)             └── Window 2: "notes"
├── Window 2: "server"                  └── Pane (terminal)
│   └── Pane (rails server)
└── Window 3: "claude"
    └── Pane (claude code)
Pane
A split within a single screen. Like nvim splits. Multiple panes visible at once side by side or stacked.
Window
A full-screen tab containing one or more panes. Like browser tabs. Only one window visible at a time. Names shown in the status bar.
Session
A complete workspace containing multiple windows. Survives disconnection — detach with C-a d, reconnect with tmux attach.
Typical workflow: One session per project. Multiple windows per concern (editor, server, tests). Panes for side-by-side within a window.

Navigation

KeyAction
no prefix C-h C-j C-k C-l Move between panes (seamless with nvim splits)
prefix 1 – 9 Jump to window by number
prefix n Next window
prefix p Previous window
prefix s List & switch sessions

Panes

KeyAction
prefix \ Split horizontal (side by side)
prefix - Split vertical (top / bottom)
prefix x Close pane
prefix z Zoom / unzoom pane (fullscreen toggle)
prefix { Swap pane up
prefix } Swap pane down

Windows

KeyAction
prefix c New window
prefix , Rename window
prefix X Close window

Sessions

KeyAction
prefix d Detach (session keeps running)
prefix s List sessions & switch
prefix $ Rename session
prefix C-s Save session (resurrect)
prefix C-r Restore session (resurrect)
From terminal: tmux new -s name to create, tmux attach -t name to reconnect, tmux ls to list.

Copy Mode

Enter with prefix [ — or scroll with mouse wheel.

KeyAction
v Begin selection
y Yank to clipboard
C-v Rectangle (block) select
/ Search forward
? Search backward
n / N Next / previous match
q or Esc Exit copy mode

Help

KeyAction
prefix / Open command palette (interactive help menu)

Homerow Mod Notes

All keybinds designed for homerow mods (Glove80 & MacBook + kmonad):

FingerTapHold
Left pinkyaCtrl
Left ringsAlt
Left middledCmd
Left indexfShift
Right indexjShift
Right middlekCmd
Right ringlAlt
Right pinky;Ctrl
C-a prefix: Hold a (becomes Ctrl at 150ms) then tap a again. Same finger twice but quick.
C-h/j/k/l nav: Hold a (Ctrl, left) + tap h/j/k/l (right hand). Bilateral, no conflict.
